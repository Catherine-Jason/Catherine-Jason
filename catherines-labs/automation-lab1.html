Automation Lab 1 - PowerShell User Account Audit

A PowerShell script that queries Active Directory, identifies inactive or non-compliant user accounts, and exports a structured CSV report for IT and security review.

Overview

Manual account audits are time-consuming and error-prone at scale. This script automates the process of pulling user account data from Active Directory, evaluating each account against defined activity thresholds, and generating a ready-to-share compliance report.

Real-world relevance: Regular account audits reduce the risk of orphaned or compromised credentials sitting undetected in your environment. This type of automation directly supports identity hygiene and access control compliance.

Objective

  • Identify user accounts that have not logged in within the last 90 days
  • Flag accounts with passwords that have never been set or have expired
  • Capture account status, last logon date, and password policy flags
  • Export findings to a CSV for IT and compliance team review

Script Walkthrough

  1. Imported the Active Directory PowerShell module and defined a 90-day inactivity threshold.
  2. Queried all enabled user accounts using Get-ADUser with relevant property filters.
  3. Calculated days since last logon for each account and compared against the threshold.
  4. Collected accounts meeting inactivity or password non-compliance criteria into a result set.
  5. Exported the result set to a timestamped CSV file for downstream review and action.

Script Preview

# Automation Lab 1 - PowerShell User Account Audit
# Queries Active Directory for inactive or non-compliant user accounts

Import-Module ActiveDirectory

$DaysInactive = 90
$CutoffDate   = (Get-Date).AddDays(-$DaysInactive)
$Timestamp    = Get-Date -Format "yyyy-MM-dd"
$OutputFile   = ".\UserAuditReport_$Timestamp.csv"

$Results = Get-ADUser -Filter {Enabled -eq $true} -Properties `
    DisplayName, SamAccountName, LastLogonDate, `
    PasswordNeverExpires, PasswordLastSet, PasswordExpired |
Where-Object {
    ($_.LastLogonDate -lt $CutoffDate -or $_.LastLogonDate -eq $null) -or
    $_.PasswordNeverExpires -eq $true -or
    $_.PasswordExpired -eq $true
} |
Select-Object DisplayName, SamAccountName, LastLogonDate,
    PasswordNeverExpires, PasswordLastSet, PasswordExpired

$Results | Export-Csv -Path $OutputFile -NoTypeInformation -Encoding UTF8

Write-Host "Audit complete. $($Results.Count) accounts flagged."
Write-Host "Report saved to: $OutputFile"

Key Skills Demonstrated

  • Active Directory querying and property filtering with PowerShell
  • Threshold-based conditional logic for account evaluation
  • Automated report generation and file output
  • Identity hygiene practices aligned with access control compliance

Tools & Technologies

  • PowerShell 5.1+
  • Active Directory PowerShell Module (RSAT)
  • Windows Server / Active Directory Domain Services
  • CSV output for reporting and compliance handoff

Results & Outcomes

  • Reduced time spent on manual account reviews from hours to seconds per audit cycle.
  • Produced a structured, auditable report identifying accounts requiring immediate action.
  • Supported compliance readiness by surfacing password policy violations and stale accounts.
  • Designed to run as a scheduled task for recurring automated audits.
