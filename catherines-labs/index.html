SOC Alert Triage Demo

An interactive browser-based simulation that puts you in the role of a Tier 1 SOC analyst. You review a suspicious login alert, investigate the context, and decide how to respond, just like you would in a real Security Operations Center.

What I Built

  • A complete decision-tree alert triage workflow in pure HTML, CSS, and JavaScript
  • Simulated alert dashboard with realistic login event data
  • Branching response paths that show consequences of each analyst decision
  • Educational feedback at each step to reinforce SOC procedures

Network Infrastructure Simulator

A drag-and-drop training game where users build and configure network topologies including routers, switches, firewalls, and end devices. Designed to teach WAN/LAN concepts, VLAN segmentation, and IP addressing through hands-on simulation.

What I Built

  • Interactive drag-and-drop canvas for building multi-device network diagrams
  • Real-time connection validation and IP addressing feedback
  • Scenario-based challenges covering LAN, WAN, VLAN, and firewall placement
  • JavaScript logic for device configuration and connectivity checks
