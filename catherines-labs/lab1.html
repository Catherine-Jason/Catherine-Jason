Lab 1 - Helpdesk Ticketing Workflow

Case study focused on real district helpdesk triage and troubleshooting workflows that support day-to-day technology operations.

Overview

This lab demonstrates full-cycle ticket handling from intake to documented resolution. It reflects practical support work completed for staff and student technology issues at district scale.

Real-world relevance: Efficient ticket triage reduces downtime for classrooms and staff operations while maintaining secure access controls.

Approach

  1. Reviewed ticket context, urgency, and affected systems.
  2. Verified user identity before sensitive account actions.
  3. Used remote troubleshooting tools to isolate root cause.
  4. Resolved MFA, password, or lockout issues and validated user access.
  5. Documented actions and final status for handoff and audit traceability.

Key Skills Demonstrated

  • Helpdesk triage and SLA-aware prioritization
  • User verification and account security procedures
  • Remote troubleshooting and guided end-user support
  • Clear technical documentation and case closure notes

Tools & Technologies

  • Quick Assist
  • Remote Desktop
  • Active Directory
  • Company Portal
  • Helpdesk ticketing platform

Results & Outcomes

  • Resolved MFA resets and account lockouts with identity verification controls.
  • Completed password recovery requests while preserving account security posture.
  • Restored user access and reduced interruption to instructional operations.
