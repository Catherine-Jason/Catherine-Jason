Lab 3: Account & Access Administration

IT Support Casework: Identity and Access Management

Identity and access management case study covering account controls, MFA workflows, and permission governance.

Home Catherine's Labs

Overview

This lab demonstrates how account security issues are handled while balancing user productivity and policy compliance.

Real world relevance: Account administration is a frontline cybersecurity control that directly impacts organizational risk.

Approach

  1. Verified user identity and request legitimacy before account changes.
  2. Performed password and MFA resets through approved workflow.
  3. Updated user/group assignments and permission scope as needed.
  4. Validated login functionality and confirmed access restoration.
  5. Documented all security-relevant changes for audit continuity.

Key Skills Demonstrated

  • Identity verification and secure account recovery process
  • Active Directory user/group administration
  • MFA lifecycle support and password control procedures
  • Role-based access and permissions alignment
Identity Verification MFA Administration Active Directory Role-Based Access Control

Tools & Technologies

  • Active Directory
  • MFA Security Info portal
  • User Management System (UMS)
  • Group Policy and permissions workflows

Results & Outcomes

  • Resolved account lockout and MFA issues while preserving access security.
  • Reduced repeat access incidents through accurate role and permission updates.
  • Maintained audit-ready documentation for identity and access events.
